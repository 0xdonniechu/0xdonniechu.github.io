# Channel Profile Contract

Adapted from ericosiu/ai-marketing-skills `packaging-youtube-thumbnails/references/channel-profile-template.md` (MIT, commit d2237ec). Save one reusable profile per channel as a text file (default: `work/youtube-channel-profile.md` in the team folder).

Required fields:

- Channel name and URL
- Profile version and review date
- Evidence sample (the thumbnails the owner supplied)
- One-sentence core formula
- Palette, subject, typography, composition, motifs, brand feel, title-thumbnail relationship, and supported variations
- Must, prefer, and avoid rules
- Component budget and grouping exceptions
- Approved subject and style reference files (names or paths the owner supplied)
- Approved co-design references, when the owner asks to retain them
- Co-design calibration: promise patterns, title patterns, visual grammar, rejected tendencies, and what must repeat versus vary
- Evidence class for each durable lesson: direct preference, owner correction, directional result, or measured performance
- Refresh gate

The refresh gate must say: refresh only when the profile is missing, the owner explicitly requests it, or the owner supplies replacement brand examples.

Keep observations separate from inference. Record YouTube A/B uncertainty and do not infer performance causality from raw views.

When the owner explicitly asks to remember a co-designed package, preserve the approved asset and calibration in the profile, increment the profile version and review date, and apply it before future ideation. Do not turn a channel-specific preference into a universal packaging rule.
