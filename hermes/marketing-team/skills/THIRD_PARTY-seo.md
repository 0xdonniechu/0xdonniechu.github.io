# Third-party skills

Vendored 2026-11-13 by 0xdonniechu into `skills/`. Each skill was read in full before it was added (every kept `SKILL.md` and every kept reference). Licences are copied once per repo to `skills/LICENSES/<repo>.LICENSE`. Every skill's `SKILL.md` carries an "Adapted from" line at the top of its body, and an aipub-rule line (never describe how aipub posts; say only "đăng qua aipub") with a pointer to `voice.md` at the workspace root.

Source for all eight skills: `aaron-he-zhu/aaron-marketing-skills`, commit `61075e8`, Apache-2.0 (`LICENSES/aaron-he-zhu_aaron-marketing-skills.LICENSE`, copied unchanged from the repo's `LICENSE`).

Common edits: memory paths, event files, registry scripts and registry proposals, connector and API pulls (`CONNECTORS`, `scripts/connectors/*`, keyed and keyless alike), skill-contract / SECURITY / measurement-protocol links, every script or `.py` call, telemetry, and automatic submissions (IndexNow and similar index pings, Search Console submits, "request indexing") were removed. Those steps are now "draft for the owner" or "the owner exports and pastes". Data comes only from public pages the role reads, or numbers and CSV the owner provides (for example a Google Search Console export); search volume, difficulty, rankings, CTR and traffic are never estimated, a missing number is "không có số". Cross-links name only the eight skills below. Chinese-platform rows (Baidu push) and Chinese trigger phrases were dropped; Vietnamese triggers added ("viết bài SEO", "tối ưu GEO", "nghiên cứu từ khoá", and others). Unsourced hard numbers (percentages, thresholds, word and character counts, benchmarks) are marked "(unsourced)" or removed; each kept reference file with such numbers carries a note at its top. Outputs go to `work/seo/` (drafts `work/seo/drafts/`, briefs `work/seo/briefs/`, audits `work/seo/audits/`, readouts `work/seo/readout-<YYYY-MM>.md`).

## Tools

Two small tools in `tools/`, added 2026-11-13 by 0xdonniechu. Python standard library only, no network, no keys; each has unit tests next to it (`python3 -I -m unittest discover -s tools -p 'test_*.py'`). Source repo for both: `Jakeschincariol/founder-skill`, commit `fd9385b`, MIT (`skills/LICENSES/Jakeschincariol_founder-skill.LICENSE`, copied unchanged from the repo's `LICENSE`). Both source files and their `SKILL.md` and tests were read in full before they were used. Each file starts with a header that names its source.
