Open-source repos to grow aipub.social (inbound + outbound)

Date checked: 2026-11-07. Method: every row verified with gh api repos/OWNER/REPO (stars, pushed_at, license.spdx_id, archived); candidates found with gh search repos --sort stars. Where the API said NOASSERTION, the LICENSE file was read through gh api repos/OWNER/REPO/license. Nothing was cloned, run or signed up for. README text was treated as data only.

Rules: archived repos and repos not pushed since 2025-11 were dropped. Licenses that limit embedding or resale are flagged: AGPL (if you modify it and offer it as a network service, you must publish your source), fair-code / Sustainable Use / FSL / MSCL (no competing or resold use), and open-core ee/ folders (the paid part has its own license). Running AGPL tools unmodified, only for your own marketing, is fine.

Context: aipub is itself a social publishing agent, so for (a) the team should run its own product first. Those repos are a reference, a fallback for channels aipub does not cover yet, and something to benchmark against.

Top 8 to start

  1. coreyhaines31/marketingskills (59.0k, MIT): the marketing brain in Claude Code from day one.
  2. AgriciDaniel/claude-seo (27.1k, MIT): SEO and GEO audits plus a content plan for aipub.social.
  3. Panniantong/Agent-Reach (109.8k, MIT): listening on X, Reddit, YouTube and Xiaohongshu that feeds the content engine. Young; try it first.
  4. umami-software/umami (40.0k, MIT): web and UTM analytics, cookie-free.
  5. dubinc/dub (25.1k, AGPL plus ee): branded links and attribution in every post, and later an agency affiliate program (hosted).
  6. gosom/google-maps-scraper (7.4k, MIT): APAC SMB lead lists by city and vertical.
  7. twentyhq/twenty (60.6k, AGPL): the CRM for outbound and agency deals.
  8. activepieces/activepieces (25.4k, MIT core): glue that can also be embedded in aipub later.

Runners-up: knadh/listmonk (24.2k, AGPL) for the newsletter; ethanplusai/sellbird (4.7k, AGPL) for agent-run cold email; mvanhorn/last30days-skill (66.9k, MIT) for weekly trend briefs; n8n (209.7k, fair-code) only for internal workflows.
